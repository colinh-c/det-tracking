Edit the tracker-to-pad geometry and rail direction measured at the field.
Nominal / unmeasured

Bearings are degrees clockwise from true North: North 0°, East 90°, South 180°, West 270°. Height is relative to the tracker; a negative value means the pad is lower. This file is a geometry foundation for Mac tracking work, not a flight-ready tracking system or a calibration result.

Site geometry

Each value keeps its own status. Editing a number does not mark it measured automatically. Distance, pad bearing and height change the pad position relative to the tracker. Rail settings do not recalculate saved OpenRocket flight physics; use an updated simulation after substantial rail or wind changes.

Export for the loader

This offline page reads only the file you select and downloads a new JSON file. It does not overwrite the project configuration or connect to hardware.

Use the saved file with local tools

Loader folder: repository root

From that folder, inspect any exported configuration with its actual file path:

python3 field_config.py --config /path/to/field_config.json

To replace the project configuration, use this import command with the downloaded file's path. The loader backs up the existing file before replacing it:

python3 field_config.py --config field_config.json --import-json /path/to/downloaded/field_config.json
