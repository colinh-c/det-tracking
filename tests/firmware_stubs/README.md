Host-only firmware test stubs copied from the original gimbal project test stubs on 2026-11-03. Added a deterministic microsecond clock and mutable/countable DRV_STATUS reads. Status-field accessors model the real library by reading DRV_STATUS. These replace hardware boundaries only; the actual launch sketch is compiled and its command handler is exercised. They do not simulate UART latency, interrupts, or physical motors.
